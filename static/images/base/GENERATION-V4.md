# Base courtyard V4

`base_courtyard_background_v4.png` was produced with the built-in ImageGen tool by editing V3 while preserving its elevated camera, enclosing wall, gates, sandstone materials, desert lighting, and teal fabric accents. The final pass keeps the nine established foundations and adds three connected expansion pads for exactly twelve visible plots.

The layout is aligned in `static/interface.css`. It contains the ten current infrastructure buildings plus two open expansion plots.

`integrated/vehicle_workshop.png` was produced with the built-in ImageGen tool using `integrated/flight_works.png` as the camera, lighting, material, and rendering reference. It uses a transparent background and depicts a low, wide ground-vehicle garage with two service bays.
